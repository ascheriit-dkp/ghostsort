### GhostSort

Tiny website for forcing a custom-ish order in Windows Explorer without putting `01_`, `02_`, `03_` in front of everything.

It abuses the invisible Unicode character `U+200B`.

Is this how you should organize your filesystem? Probably not.  
Does it work? Apparently.

Give it a number of items, copy the generated prefixes and put them in front of your filenames.

Here u go : https://ascheriit-dkp.github.io/ghostsort/

Just a static page generating invisible characters.

Anyway, have fun.
